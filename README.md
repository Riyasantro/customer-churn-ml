# Customer Churn Prediction

A machine learning project for predicting customer churn from telecom customer data.

The dataset contains customer information such as tenure, services, contract type, payment method, monthly charges and total charges. The goal is to build a model that can identify customers who are more likely to leave.

## Project structure

```text
customer-churn-ml/
├── data/
├── notebooks/
├── src/

├── requirements.txt
└── .gitignore
```

## Dataset

This project uses the Telco Customer Churn dataset, also known as the IBM Telco Customer Churn sample dataset.

The raw CSV is not included in this public repository. Download the dataset and place it here before running the notebook:

```text
data/WA_Fn-UseC_-Telco-Customer-Churn.csv
```

## Tools

Python, Pandas, NumPy, Matplotlib, Seaborn and Scikit-learn.

## Status

The project is being developed incrementally, with the code and model decisions built from the data rather than starting with a fixed final implementation.
